# Marco Casaroli

I’m an embedded systems engineer and real-time operating systems (RTOS) enthusiast with expertise in networking, cybersecurity, and RTOS development.

I contribute to [Zephyr](https://github.com/zephyrproject-rtos/zephyr/pulls?q=is%3Apr+author%3Acasaroli) and am an [Apache NuttX committer](https://nuttx.apache.org/community-members/). My upstream work includes POSIX I/O in Zephyr and process and thread lifecycle handling in NuttX. [NuttX contributions](https://github.com/apache/nuttx/pulls?q=is%3Apr+author%3Acasaroli)

I’m also a sound synthesis and modular synthesizer enthusiast.

## Selected projects

### Pre-AI

- [Momote](https://inatel.br/noticias/uma-solucao-para-conectar-todas-as-coisas) — A low-cost, open-source IoT hardware module I developed during my master’s research at Inatel.
- [NovaGenesis](https://github.com/antonioalberti/novagenesis) — An experimental Internet architecture and Linux networking stack built around named services and data.
- [Maritime Hacking Village Badge 2025](https://github.com/Maritime-Hacking-Village/Badge-2025) — An open hardware badge built around the Raspberry Pi Pico 2, with Rust firmware.
- [Edge Virtualization Platform](https://github.com/SonySemiconductorSolutions/edge-virtualization-platform) — Sony Semiconductor Solutions’ open-source edge virtualization platform.
- [Linux on Raspberry Pi Pico 2](https://github.com/casaroli/pi-pico2-linux-xip) — A fork that runs RISC-V Linux on the Pico 2 using execute-in-place (XIP).
- [Ocre Runtime](https://github.com/project-ocre/ocre-runtime) — A lightweight WebAssembly runtime for application containers on Zephyr and Linux.
- [repo-dispatch](https://github.com/casaroli/repo-dispatch) — Triggers GitHub Actions workflows across repositories and reports their status back to the originating commit.
- [raspios-lite-docker-img](https://github.com/casaroli/raspios-lite-docker-img) — Builds Docker images from Raspberry Pi OS Lite.
- [qnq](https://github.com/casaroli/qnq) — No longer maintained.
